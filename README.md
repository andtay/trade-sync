# trade-sync
TradeSync Analytics is a performance auditing middleware for retail traders. We use the Trader API to securely sync execution data and calculate advanced KPIs. Our platform provides data-driven insights through a secure 3-legged OAuth flow, ensuring encryption and strict privacy standards for all user trading data.


# TradeSync Analytics Engine

This repository hosts the public-facing documentation and legal framework for the TradeSync Analytics SaaS.

## Project Scope
TradeSync is a secure middleware designed to bridge institutional brokerage data (Charles Schwab) with advanced performance auditing tools.

## Security Compliance
- **Authentication:** 3-Legged OAuth 2.0.
- **Data Protection:** AES-256 encryption at rest.
- **Integrity:** Mandatory Refresh Token Rotation.
- **Privacy:** Time-delayed aggregate analysis on closed positions only.
